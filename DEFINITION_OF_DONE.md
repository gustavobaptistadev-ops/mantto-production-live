# DEFINITION OF DONE

Uma tarefa só é `DONE` quando:

- [ ] código implementado
- [ ] testes criados
- [ ] testes passando
- [ ] lint passando
- [ ] typecheck passando
- [ ] segurança verificada
- [ ] documentação atualizada
- [ ] contratos atualizados
- [ ] contexto atualizado (`PROJECT_STATUS.md`, task, handoff/checkpoint)
- [ ] reviewer aprovado
- [ ] nenhuma regressão conhecida

## Checklist do Reviewer
Arquitetura · segurança · testes · performance · concorrência · idempotência · tratamento de erros · logs · documentação.
