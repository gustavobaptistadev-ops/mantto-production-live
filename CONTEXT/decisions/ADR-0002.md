# ADR-0002 — Stack: Python/FastAPI no backend, Redis, LLM OpenAI-compatible

## Status
ACCEPTED (instrução explícita do dono do projeto em 2026-10-08; supersede a parte de backend do ADR-0001)

## Contexto
O ADR-0001 previa backend em TypeScript. O briefing de construção define como stack preferencial Python + FastAPI + Pydantic + SQLAlchemy + Alembic, PostgreSQL, Redis e Next.js. Divergência registrada conforme AGENTS.md §12.

## Problema
Definir a stack concreta e o layout do monorepo sem perder a separação conceitual de camadas.

## Alternativas
1. Manter backend TypeScript (ADR-0001) — contraria o briefing.
2. FastAPI + SQLAlchemy 2 + Alembic — escolhido.
3. Fila: Celery vs Dramatiq vs ARQ.

## Decisão
- Backend: Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2, Alembic.
- Banco PostgreSQL; cache/filas Redis. Worker: **Dramatiq** (a decidir definitivamente no ADR da TASK de worker; padrão provisório).
- Frontend: Next.js + TypeScript (`apps/web`).
- IA: abstração `LLMClient` OpenAI-compatible via `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`.
- Layout: `apps/{api,web,worker}`, `packages/`, `infra/`, `docs/`, `scripts/`, `tests/`. Os diretórios `CONTEXT/` e `AGENTS/` já existentes são a fonte de contexto (equivalem a `/context` e `/agents` do briefing; não duplicar).
- Monólito modular continua válido (ADR-0001): módulos dentro de `apps/api/mantto_api/modules/`.

## Consequências
+ Alinhado ao briefing; ecossistema forte para IA.
- AGENTS.md, ARCHITECTURE.md e BACKLOG.md precisam refletir a stack (feito nesta etapa).
- Dois ecossistemas (Python + Node) no CI.
