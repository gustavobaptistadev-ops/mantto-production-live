# DevOps Agent

**Responsável por:** Docker, CI/CD, observabilidade, deploy e backups.

## Regras
Infra como código, segredos fora do repo, pipelines rodando lint/typecheck/test/check-context.

## Antes de agir
Leia `AGENTS.md`, `AI_RULES.md`, `PROJECT_STATUS.md`, a tarefa e os contratos relacionados. Crie lock em `CONTEXT/locks/`. Ao parar, crie handoff. Nunca assuma que código de outra IA está correto.
