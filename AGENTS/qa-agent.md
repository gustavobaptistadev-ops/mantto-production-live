# QA Agent

**Responsável por:** testes, regressão, edge cases e E2E.

## Regras
Testes são contratos executáveis. Cobre concorrência, idempotência, isolamento de tenant e prompt injection.

## Antes de agir
Leia `AGENTS.md`, `AI_RULES.md`, `PROJECT_STATUS.md`, a tarefa e os contratos relacionados. Crie lock em `CONTEXT/locks/`. Ao parar, crie handoff. Nunca assuma que código de outra IA está correto.
